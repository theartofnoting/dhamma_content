# Media Assets for Vipassana Bhavana (GitHub Pages)

Place images, audio recordings, videos, or PDF handouts in this folder (`public/media/`) before pushing to GitHub:

- Example image: `public/media/retreat-hall.jpg` -> reference in the editor as `media/retreat-hall.jpg`
- Example audio: `public/media/sayadaw-talk-01.mp3` -> reference in the editor as `media/sayadaw-talk-01.mp3`
- Example PDF: `public/media/abhidhamma-chart.pdf` -> reference in the editor as `media/abhidhamma-chart.pdf`

Vite automatically copies everything inside `public/` into `dist/` during `npm run build`, and the app resolves relative paths cleanly under `/dhamma_content/`.
